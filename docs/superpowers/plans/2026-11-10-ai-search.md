# AI search ("Ask") on the deals page: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a cost-capped, read-only Claude "Ask" search to steam-wishlist-deals at `/deals/ask` (and `/ask`), matching the Ask that steam-backlog-triage shipped.

**Architecture:** Three new stdlib modules. `deals_query.py` is the read layer over `deals.json`'s `games` and the live `targets.json`, mirroring the page's scope, filter and sort rules. `access_jwt.py` is triage's file copied. `ask.py` is triage's adapted: settings, gate, tool loop, log and caps. `deals_server.py` gains the page routes, `GET .../api/deals/ask/status` and `POST .../api/deals/ask` under both prefixes. `deals.html` gains an `ask` mode, a header pill, a thread view, and `row(g, opts)`.

**Tech Stack:** Python 3.11+ standard library only, vanilla JS in the single `deals.html`, `unittest`, the openssl CLI (JWT tests), Playwright as pinned in `tests/browser/requirements.txt`.

**Spec:** `docs/superpowers/specs/2026-11-ai-search-design.md` (approved 2026-11-10). Read it before any task; §n refers to it.

**Reference (read-only):** `steam-backlog-triage` at `7468859`, cloned beside this repo as `../steam-backlog-triage` (clone it if missing). Its `ask.py`, `access_jwt.py`, `tests/test_ask.py`, `tests/test_access_jwt.py`, `tests/ask_shim.py`, `tests/browser/test_ask_page.py`, the Ask parts of `backlog.html` (`CHAT_ICON`, `#chatTop` CSS, `renderChat`), `install/alpine.sh` lines 96–125 and README "AI search (Ask)" are the source to copy from. ## Review Focus

1. **`deals.json` damaged or half-written by hand** (not valid JSON). Ask should answer through the model with "No deals list on the server yet." and a 200, not a 502. → `test_unreadable_snapshot_is_no_list` in Task 4.
2. **`targets.json` unreadable** (the server's own `TargetsUnreadable`). Scopes and rows still work with no targets; `get_overview` and `get_targets` say targets couldn't be read. → `test_unreadable_targets_degrade` in Task 1 and `test_snapshot_targets_unreadable` in Task 4.
3. **The model sends values outside the schema** (`min_cut: 40`, `scope: "cheap"`, `deck: "yes"`, `sort: "best"`, `min_rating: 140`). Schemas are advisory to the model; `deals_query` must refuse with a message naming the allowed values. → `test_out_of_range_arguments` in Task 1.
4. **Games with no price** (ITAD lists no store), including bundle-only games whose tier has no price. `sort: price` puts them last, `max_price` never matches them. → `test_no_price_sorts_last_and_never_under_max` in Task 1.
5. **Deals that expired after the last check** (snapshot hours old). `ends_in_days` is null for a past expiry, as the page shows nothing. → `test_past_expiry_has_no_ends_in` in Task 1.
